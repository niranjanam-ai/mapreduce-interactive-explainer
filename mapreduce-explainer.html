MapReduce

A programming model for processing massive datasets in parallel across many machines — split, transform, sort, and aggregate.

// Core Idea

MapReduce breaks a huge problem into smaller chunks, processes each chunk independently (Map), then merges the results (Reduce). It's like splitting a massive spreadsheet among 100 people, having each count their section, then adding all counts together.

// The 5 Phases
📥
01

Input

Raw data — could be millions of lines, log files, or records from a database.

✂️
02

Splitting

The input is divided into equal-sized chunks so multiple workers can process in parallel.

🗺️
03

Mapping

Each worker processes its chunk and emits key-value pairs. e.g. ("apple", 1)

🔀
04

Shuffling

All pairs with the same key are grouped together and sent to the same reducer.

📊
05

Reducing

Each reducer aggregates its group of values into a single output: the final answer.

Step-by-Step Walkthrough

1

Input Data

You start with a sentence (or millions of lines of text, logs, etc.):

// The raw input
"the cat sat on the mat the cat"
2

Split into Chunks

The framework divides data into 3 equal pieces — each handled by a separate worker (mapper).

// Worker 1 gets: "the cat sat"
// Worker 2 gets: "on the mat"
// Worker 3 gets: "the cat"
3

Map Phase — Emit Key-Value Pairs

Each worker reads its words and emits a (word, 1) pair for every word it sees. Workers run in parallel.

// Worker 1 emits:
(the,1) (cat,1) (sat,1)

// Worker 2 emits:
(on,1) (the,1) (mat,1)

// Worker 3 emits:
(the,1) (cat,1)
4

Shuffle & Sort — Group by Key

The framework automatically collects all pairs with the same key and groups them together. This is done automatically — you don't write this code.

the → [1, 1, 1]
cat → [1, 1]
sat → [1]
mat → [1]
on → [1]
5

Reduce Phase — Aggregate

Each reducer receives one key and its list of values, then produces a final answer by summing (or any other operation).

function reduce(key, values) {
  return (key, sum(values));
}

// reduce("the", [1,1,1]) → ("the", 3)
// reduce("cat", [1,1]) → ("cat", 2)
// reduce("sat", [1]) → ("sat", 1)
6

Final Output

The results from all reducers are collected into the final output — a word frequency count.

the: 3   cat: 2   sat: 1   mat: 1   on: 1

// Real-World Analogy

Imagine you have 10,000 survey forms to tally. Instead of one person counting all of them, you give 100 friends 100 forms each (splitting). Each friend reads their forms and writes down tallies on sticky notes — one note per answer (mapping). Then you collect all the sticky notes and group them by answer (shuffling). Finally, each pile gets counted by one person (reducing), and you combine all those totals into your final report.

That's MapReduce. Divide the work. Process in parallel. Merge the results.
